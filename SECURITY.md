# Security

Please **do not** open public issues for vulnerabilities.

Email **security@shizuha.com** with:

- a description of the issue
- steps to reproduce
- impact (if known)

We will acknowledge receipt and work on a fix before any public disclosure.

This project is AGPL-3.0-or-later. Agents can run shell and file tools; treat
untrusted workspaces as untrusted code.
